Before your first race — Controls

WASD / Arrow keys drive & steer · Space nitro · R reset to track · P pause. Touch: left steering zones, right gas / brake, nitro above brake. Gamepad: left stick steers, RT gas, LT brake, A nitro. Keys are remappable in Settings. Arrow keys and WASD are captured by the game so they do not scroll the parent Google Sites page.

Quick Race

AI personalities in every race: drivers mix aggressive, defensive, and clean styles — difficulty sets their speed, personality sets how they race you.

Multiplayer lobby

This lobby is the hub for the next race. Pick the game here, start it from here, and after the race you come back here for the next one — you do not drop back to the main menu. Remote play uses Firebase Realtime Database (free tier, anonymous auth only). Firebase connecting… If online is unavailable, the lobby works locally / offline vs AI. The game never shows a blank screen: if online is unavailable, race offline vs AI, local 2-player, or Time Trial instead.

Settings & accessibility

Remap controls

Click a field, then press the key you want. Defaults: Up=W / Down=S / Left=A / Right=D / Nitro=Space.

Reset progress: first click arms it, second click within 10 seconds wipes credits, designs, career and best laps. This cannot be undone.

How to test & embed

Full steps are in README.md next to this file: host this single file on GitHub Pages / Netlify / Apps Script, then in Google Sites use Insert > Embed > Embed code, paste the hosted URL in an iframe, set full width and at least 900px tall, and Publish. Test on desktop Chrome, a Chromebook on Low graphics, and a phone in portrait.
